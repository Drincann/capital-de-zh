# 第十六章 剩余价值率的各种公式

我们已经看到，剩余价值率可以用下面几种相等的比率表示：

\[
\text{I)}\qquad
\frac{\text{剩余价值 }m}{\text{可变资本 }v}
=
\frac{\text{剩余价值}}{\text{劳动力价值}}
=
\frac{\text{剩余劳动}}{\text{必要劳动}}
\]

前两个比率用价值表示这种关系，第三个比率则用生产这些价值所花的时间来表示。三者可以相互替换，而且概念非常严密。古典政治经济学实际上也使用过这些关系，却没有把它们明确整理成公式。与此不同，我们还会看到下面这组从它们推导出来的公式：

\[
\text{II)}\qquad
\frac{\text{剩余劳动}}{\text{整个工作日}}
=
\frac{\text{剩余价值}}{\text{当天新创造的全部价值}}
=
\frac{\text{剩余产品}}{\text{全部产品}}
\]

这三个比率仍然表示同一个比例，只是依次用劳动时间、劳动形成的价值和体现这些价值的产品来表示。这里所说的“当天新创造的全部价值”，不包括生产资料转移到产品中的那部分原有价值。

这组公式不能正确表示劳动实际受到的剥削程度，也就是剩余价值率。假定工作日为十二小时，其他条件仍与前面的例子相同。劳动实际受到的剥削程度应当这样计算：

\[
\frac{6\text{ 小时剩余劳动}}{6\text{ 小时必要劳动}}
=
\frac{3\text{ 先令剩余价值}}{3\text{ 先令可变资本}}
=100\%
\]

按照第二组公式计算，得到的却是：

\[
\frac{6\text{ 小时剩余劳动}}{12\text{ 小时工作日}}
=
\frac{3\text{ 先令剩余价值}}{6\text{ 先令新创造的全部价值}}
=50\%
\]

第二组公式真正表示的，是工作日或当天新创造的价值怎样在资本家和工人之间分配。如果把它们直接当成资本增殖程度的公式，就会得出一条错误的规律：剩余劳动或剩余价值永远不可能达到 100%。[^17] 原因很简单。剩余劳动只是工作日的一部分，剩余价值也只是当天新创造价值的一部分，所以分子必然小于分母。要达到 \(100/100\)，二者就必须相等。也就是说，剩余劳动必须占满整个工作日，而必要劳动必须降为零。这里说的是一周、一年等较长时期内的平均工作日。可是必要劳动一旦消失，剩余劳动也会随之消失，因为剩余劳动只有在必要劳动存在的前提下才存在。因此，\(\text{剩余劳动}/\text{工作日}\) 或 \(\text{剩余价值}/\text{新创造的全部价值}\) 永远不可能达到 \(100/100\)，更不可能上升到 \((100+x)/100\)。剩余价值率，也就是劳动实际受到的剥削程度，却完全可以超过 100%。例如，拉韦涅估计，英国农业工人只得到产品或其价值的四分之一，资本家，也就是租地农场主，得到四分之三。[^18] 至于这份所得后来怎样在资本家、土地所有者等人之间再分配，并不影响这里的计算。按这个估计，英国农业工人的剩余劳动与必要劳动之比是 \(3:1\)，剥削程度就是 300%。

第二组公式还强化了一种教科书式的做法：把工作日看成一个固定量。因为在这些公式中，剩余劳动总是同一个长度已经确定的工作日相比。只看当天新创造的价值怎样分配，也会产生同样的效果，因为这笔价值所体现的工作日已经结束，长度当然已经确定。

把剩余价值和劳动力价值都表示成当天新创造价值的一部分，是资本主义生产方式本身造成的。它的意义以后还会说明。不过，这种表示方法遮住了资本关系的特殊之处：资本家用可变资本购买活的劳动力，工人却无权占有自己生产的产品。于是，这种关系看起来反倒像一种合作关系，好像工人和资本家分别贡献了不同的生产要素，再按各自要素所占的比例分配产品。[^19]

[^17]: 例如，罗德贝尔图斯在《致冯·基尔希曼的第三封信：驳斥李嘉图的地租理论并建立一种新的地租理论》（柏林，1851 年）中就提出过这种说法。我以后还会谈到这篇著作。它的地租理论虽然错误，却看透了资本主义生产的实质。——第三版增补：这里可以看出，只要前人真正向前迈了一步，提出一个正确的新思想，马克思就会多么宽厚地评价他。不过，罗德贝尔图斯致鲁道夫·迈耶的书信后来出版，使上面的赞许不得不打些折扣。他在那里写道：“不仅要从劳动手中拯救资本，也要从资本自身手中拯救资本。最好的办法，是把企业资本家的活动看成资本所有权赋予他的国民经济和国家经济职能，把他的利润看成一种薪金，因为我们还不知道别的社会组织形式。薪金可以受到管理，如果它从工资中拿走太多，也可以降低。这样也能挡住马克思对社会的闯入——我愿意这样称呼他的书……总的说来，马克思的书与其说是研究资本，不如说是批判资本今天的形式。他把这种形式同资本概念本身混为一谈，他的错误正是由此产生的。”（《罗德贝尔图斯—亚格措夫博士书信集》，鲁道夫·迈耶博士编，柏林，1881 年，第 1 卷，第 111 页，第 48 封信。）罗德贝尔图斯《社会书信》中那些确实大胆的开端，最终就搁浅在这类意识形态套话里。——恩格斯

[^18]: 这项计算已经扣除了产品中仅用来补回预付不变资本的部分。拉韦涅先生盲目崇拜英国，所以他的估计即使有偏差，也更可能偏低而不是偏高。

[^19]: 资本主义生产过程的一切发达形式都是协作形式。因此，人们很容易抽掉其中特有的对抗性质，再把它编成自由联合的故事。拉博德伯爵的《论共同体一切利益中的联合精神》（巴黎，1818 年）就是这样做的。美国人凯里甚至能用同样的手法解释奴隶制度，而且同样得心应手。

第二组公式随时可以还原成第一组公式。例如，已知十二小时工作日中有六小时剩余劳动，必要劳动时间就是十二小时减六小时，仍为六小时。因此：

\[
\frac{6\text{ 小时剩余劳动}}{6\text{ 小时必要劳动}}
=
\frac{100}{100}
=100\%
\]

还有第三组公式，我在前文已经偶尔提前用过：

\[
\text{III)}\qquad
\frac{\text{剩余价值}}{\text{劳动力价值}}
=
\frac{\text{剩余劳动}}{\text{必要劳动}}
=
\frac{\text{未付报酬的劳动}}{\text{已付报酬的劳动}}
\]

“未付报酬的劳动与已付报酬的劳动之比”可能让人误以为，资本家付钱购买的是劳动，而不是劳动力。经过前面的分析，这种误解已经可以排除。这个说法只是“剩余劳动与必要劳动之比”的通俗表达。资本家支付的是劳动力的价值，或者与这一价值有所偏离的价格，换来的则是对活劳动力本身的支配。劳动力的使用分为两个阶段。在第一个阶段，工人只生产出等于自己劳动力价值的价值，也就是一个等价物。资本家预付了劳动力的价格，得到一个价格相同的产品，就像从市场上买来一件成品。在剩余劳动阶段，资本家使用劳动力得到新的价值，却不用为这部分价值付出等价物。[^20] 劳动力在这段时间里的发挥，对资本家来说是免费的。正是在这个意义上，剩余劳动可以叫作未付报酬的劳动。

所以，资本不只是亚当·斯密所说的对劳动的支配。它在本质上是对未付报酬劳动的支配。剩余价值以后无论采取利润、利息、地租等哪种具体形式，归根到底都是未付报酬劳动时间的产物。资本能够自行增殖的秘密，就在于它能支配一定数量的他人无偿劳动。

[^20]: 重农学派虽然没有看透剩余价值的秘密，却至少已经清楚，它是“一种独立的、可供支配的财富。它的所有者没有买过它，却把它拿来出售”。（杜尔哥：《关于财富的形成和分配的思考》，第 11 页。）
