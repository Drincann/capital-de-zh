# 第四版序言

第四版要求我尽可能把正文和注释最终确定下来。下面简要说明我是怎样做的。

我再次核对法文版和马克思的手写批注，又从法文版选了几处增补收入德文正文。它们见本版第80页（第三版第88页）、第458—460页（第三版第509—510页）、第547—551页（第三版第600页）、第591—593页（第三版第644页），以及第596页（第三版第648页）的注79。参照法文版和英文版，我还把关于矿工的长注（第三版第509—515页）移入正文（第四版第461—467页）。其他小改动纯属技术处理。

此外，我还加了几条解释性注释，主要用在历史情况已经发生变化、因而需要说明的地方。这些补注都放在方括号里，并用我的姓名首字母或“D. H.”标明。

英文版问世后，书中大量引文必须全面核校。为了出版英文版，马克思的小女儿埃莉诺费了很大工夫，把所有引文同原文逐一核对。书中绝大多数引文来自英语资料，因此英文版不再把德文引文译回英语，而是直接采用英语原文。编第四版时，我也必须参考这些原文。核对中发现了各种小问题。有的是页码错了：有些抄自笔记时就写错了，有些是经过三版积累的印刷错误。有的引号或省略号位置不对。大量引文来自摘录本，这类错误很难避免。个别译词也选得不够好。还有几段引自马克思1843—1845年的巴黎笔记。当时他还不懂英语，读英国经济学家的著作时用的是法文译本。这些引文经过两次翻译，语气难免略有变化，斯图亚特和尤尔等人的引文就是如此，现在应当改用英语原文。此外还有其他类似的小错误和疏忽。不过，把第四版同前几版比较就会发现：这一整套费力的校正，没有给全书带来任何值得一提的改变。只有一条出自理查德·琼斯的引文没能找到出处（第四版第562页注47）。马克思大概写错了书名。其余引文仍然完全具备证明力，经过准确核校后有些反而更有力。

说到这里，我不得不再提起一桩旧事。

据我所知，只有一次有人质疑马克思的引文是否准确。这场争论一直延续到马克思去世以后，因此不能不在这里说明。

1872年3月7日，德国工厂主协会的机关刊物《协和》发表了一篇匿名文章，题为《卡尔·马克思怎样引用》。文章满篇义愤和粗暴用语，声称马克思伪造了英国财政大臣格莱斯顿1863年4月16日预算演说中的一句话。这句引文曾出现在1864年的《国际工人协会成立宣言》中，后来又收入《资本论》第一卷第四版第617页、第三版第671页。引文是：“这种令人陶醉的财富和力量增长……完全只限于有产阶级。”匿名文章说，近乎官方的《汉萨德》速记记录根本没有这句话：“这句话根本不在格莱斯顿的演说中。演说说的恰恰相反。马克思无论从形式还是内容上，都凭空捏造了这句话！”最后一句还特意用了黑体。

同年5月，马克思收到了这一期《协和》，并于6月1日在《人民国家报》上答复那位匿名作者。他已经记不清自己当初引用的是哪家报纸的报道，因此先在两本英国出版物中找出了内容相同的引文，接着引用《泰晤士报》的报道。按照这篇报道，格莱斯顿说：“就本国财富而言，情况就是这样。就我个人来说，如果我相信这种令人陶醉的财富和力量增长只限于生活优裕的阶级，我会近乎忧虑和痛苦地看待它。这里完全没有考虑劳动人口的状况。我刚才描述的增长——我认为它以准确的统计为依据——完全只限于有产阶级。”

可见，格莱斯顿在这里说的是：如果情况真是这样，他会感到遗憾，但事实确实如此——这种令人陶醉的财富和力量增长，完全只限于有产阶级。至于近乎官方的《汉萨德》，马克思接着说：“在后来胡乱修订的版本里，格莱斯顿先生很聪明地把这段话删掉了。这段话出自英国财政大臣之口，确实会让他难堪。这本来就是英国议会的惯例，并不是那位小拉斯克为对付倍倍尔才发明的手段。”

匿名作者越发恼怒。他在7月4日《协和》刊出的答复中，撇开自己使用的二手资料，只含蓄地说，引用议会演说的“惯例”是依据速记记录。然而他又声称，《泰晤士报》的报道——其中明明有那句被说成“捏造”的话——同《汉萨德》的报道——其中没有这句话——“实质上完全一致”。他还说，《泰晤士报》表达的是《国际工人协会成立宣言》中那句著名引文的“直接反面”。但他小心地隐瞒了一个事实：《泰晤士报》在写出这个所谓“反面”的同时，也明确写出了那句著名引文。即使这样，匿名作者也感到自己已经走投无路，只有再耍一个花招才能脱身。他的文章刚刚被证明充斥着“厚颜无耻的谎言”，他却仍用一串道貌岸然的辱骂来装点文章：“恶意”、“不诚实”、“虚假陈述”、“那条虚假引文”、“厚颜无耻的谎言”、“一条完全伪造的引文”、“这次伪造”、“简直卑鄙”，等等。为了把争论转到别处，他答应在“第二篇文章中说明，我们怎样理解格莱斯顿这句话的含义”。这里的“我们”，就是那位自称并不“撒谎”的匿名作者。仿佛他那无关紧要的看法同问题有任何关系似的！这第二篇文章刊于7月11日的《协和》。

8月7日，马克思再次在《人民国家报》上答复。这一次，他又引用了1863年4月17日《晨星报》和《晨间广告报》对争议段落的报道。两家报纸都写道：格莱斯顿说，如果他认为这种令人陶醉的财富和力量增长只限于真正富裕的阶级，他会深感忧虑。但这种增长实际上完全只限于有产阶级。可见，这两篇报道也逐字载有那句被指为“凭空捏造”的话。马克思还再次比较《泰晤士报》和《汉萨德》的文本，并指出：第二天早晨出版的三家报纸彼此独立，却都用相同文字记下了这句话，足以证明格莱斯顿确实说过。但《汉萨德》按照众所周知的“惯例”审订后，这句话却不见了。用马克思的话说，格莱斯顿后来把它“悄悄删掉了”。最后，马克思声明自己没有时间再同匿名作者周旋。对方似乎也不想再争下去了，至少此后再没有人把《协和》寄给马克思。

事情似乎就此结束，彻底被埋葬了。后来，我们确实有一两次从同剑桥大学有来往的人那里听到神秘传言，说马克思在《资本论》中犯下了某种不可告人的学术罪行。可是，无论怎样追问，都得不到任何具体内容。直到1883年11月29日，也就是马克思去世八个月后，《泰晤士报》刊出一封来信。信从剑桥三一学院寄出，署名塞德利·泰勒。这个一向以温和合作派自居的小人物，借一个生拉硬扯的话题，终于向我们说明了剑桥流言的来历，也暴露了《协和》匿名作者的身份。

这位三一学院的小人物写道：“极其奇怪的是，竟然要由布伦坦诺教授（当时在布雷斯劳，现已到斯特拉斯堡）来……揭露那种显然导致《成立宣言》这样引用格莱斯顿演说的‘恶意’。卡尔·马克思先生……试图为这条引文辩护。但布伦坦诺高明的攻击很快把他逼进了‘垂死挣扎’，而他竟敢在挣扎中声称：格莱斯顿先生在1863年4月17日《泰晤士报》的演说报道刊入《汉萨德》以前，亲手把它胡乱修改了一番，为的是删掉一段确实会让英国财政大臣难堪的话。后来，布伦坦诺逐字比较两份报道，证明《泰晤士报》和《汉萨德》完全一致，都根本不含那种被马克思‘巧妙截取的孤立引文’硬塞给格莱斯顿原话的意思。马克思这才借口没有时间，退出了争论！”

原来真相竟是这样！布伦坦诺先生在《协和》发动的匿名攻势，到了剑桥这位生产合作派的想象中，竟变成了如此辉煌的英雄史诗！德国工厂主协会的圣乔治就是这样挺立着，挥剑发动那场“高明的攻击”。地狱恶龙马克思则倒在他脚下，“迅速陷入垂死挣扎”，咽下最后一口气！

不过，这整段骑士史诗般的战斗描写，只是为了遮住我们这位圣乔治耍的花招。现在，指控已经不再是“凭空捏造”或“伪造”，而变成了“巧妙截取的孤立引文”。整个问题已经被换掉。我们的圣乔治和他那位剑桥侍从都很清楚为什么要这样做。

《泰晤士报》拒绝刊登埃莉诺·马克思的答复，她只好把文章发表在1884年2月的月刊《今日》上。她把争论拉回唯一的问题：马克思究竟有没有“凭空捏造”那句话？塞德利·泰勒先生回答说，同马克思引用这句话时“是想忠实表达还是歪曲格莱斯顿的意思”相比，“格莱斯顿先生的演说里究竟有没有某句话”在他看来“只是非常次要的问题”。接着，他承认《泰晤士报》的报道“确实记录了格莱斯顿话中的矛盾”。可是，只要用“正确”的方式解释其余上下文——也就是按照自由党人维护格莱斯顿的方式来解释——就能看出格莱斯顿本来想说什么。（《今日》，1884年3月。）最滑稽的是，这位剑桥小人物现在坚持不按《汉萨德》引用演说，尽管匿名的布伦坦诺曾说那才是“惯例”。他反而要采用《泰晤士报》的报道，而布伦坦诺本人恰恰说过，这类报道“必然很粗糙”。原因当然很简单：那句要命的话在《汉萨德》中根本不存在！

埃莉诺·马克思在同一期《今日》上轻易驳倒了这套说法。泰勒先生如果读过1872年的争论，那么他现在就在“撒谎”，既凭空加进了东西，也故意删掉了东西。如果他没有读过，就应当闭嘴。无论如何，可以确定的是，他根本不敢继续坚持朋友布伦坦诺的原指控：马克思“凭空捏造”了那句话。相反，现在的说法变成了马克思没有捏造，却隐瞒了一句重要的话。可是，就在《成立宣言》第5页，那句重要的话也被引用了，只比那句据说由马克思“捏造”的话早几行。至于格莱斯顿演说中的“矛盾”，难道不正是马克思本人在《资本论》第618页（第三版第672页）注105中所说的“格莱斯顿1863年和1864年预算演说中一连串刺眼的矛盾”吗？只不过，马克思没有仿效塞德利·泰勒，用维护自由党的解释把这些矛盾化解掉。埃莉诺·马克思最后总结说：“事实正好相反。马克思既没有删掉任何值得引用的内容，也没有凭空捏造哪怕一点东西。他只是恢复了格莱斯顿演说中的一句话，使它免于被人遗忘。这句话毫无疑问确实说过，却不知通过什么方式，从《汉萨德》中消失了。”

塞德利·泰勒先生也就此罢手了。这场教授小圈子的勾连跨越两个大国，延续了二十年，最后的结果是：再也没有人敢攻击马克思在引用文献方面的严谨。此后，泰勒先生大概不会再轻信布伦坦诺先生发布的学术战报，正如布伦坦诺先生不会再相信《汉萨德》拥有教皇般绝不犯错的权威。

伦敦，1890年6月25日。

弗·恩格斯
