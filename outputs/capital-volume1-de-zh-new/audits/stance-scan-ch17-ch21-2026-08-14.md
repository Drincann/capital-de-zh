## Findings

### S-01：把资本家的“骗术”解释中性化为一般买卖结果

- Unit / version / task / source-id：`ch17-s01` / `ch17-s01-v1` / `ch17-p0016-p0020-r1` / `v1-ch17-p0019`
- 当前中文摘录：“不过，资本家购买其他商品时也总想压低价格，并习惯把利润解释成买得低于价值、卖得高于价值的结果。”
- 源文实际立场及功能：马克思不是中性转述一种利润来源说，而是把资本家自己的解释称作 `die einfache Prellerei`，即一种“简单的骗术/欺诈”：低于价值买进、高于价值卖出。这个贬义命名既揭示该解释的粗陋，也为下文“因此他看不到……”提供带批判距离的因果衔接；说话者是马克思，评价对象是资本家的利润观。
- 为什么是 S：中文仍准确保留“资本家把利润解释成低买高卖”以及马克思对其认识局限的批判，评价对象和论证走向均未改变；但删去“骗术/欺诈”后，原文直接的贬斥与距离化明显变弱，成为较中性的观念陈述。因此是实质可感但未改换读法方向的 S，而非 T。
- 建议重译：“不过，资本家购买其他商品时也总想压低价格，并总把利润解释成一种简单的骗术：低于价值买进、高于价值卖出。正因如此，他看不到……”

### S-02：计件工资作为资本家欺诈“最为多产的源泉”的力度下降

- Unit / version / task / source-id：`ch19-s01` / `ch19-s01-v1` / `ch19-p0006-p0010-r2` / `v1-ch19-p0008`
- 当前中文摘录：“因此，计件工资很容易成为扣工资和欺骗工人的手段。”
- 源文实际立场及功能：原文说计件工资在这一方面成为 `fruchtbarster Quelle von Lohnabzügen und kapitalistischer Prellerei`，即扣减工资和资本家欺诈“最为多产的源泉/温床”。`fruchtbarster` 不是仅说这种制度“容易被利用”，而是以强烈判断凸显这种工资形式系统性滋生克扣和欺诈；欺诈的施事者也明确是资本家。
- 为什么是 S：中文保留了批评方向、受害者和“扣工资/欺骗”两种行为，读者不会误判马克思的基本立场；但“很容易成为……手段”同时降低了最高级力度，并把“资本家欺诈”泛化成“欺骗工人”，弱化了制度性、繁殖性的指控。主要读法仍在，故列 S。
- 建议重译：“因此，就这一点说，计件工资成了扣减工资和资本家欺诈最为多产的温床。”

### S-03：对资产阶级经济学家“狭隘头脑”和主动闭眼的蔑视被压平

- Unit / version / task / source-id：`ch21-s01` / `ch21-s01-v1` / `ch21-p0006-p0010-r1` / `v1-ch21-p0007`
- 当前中文摘录：“资产阶级经济学家分不清外在形式和形式背后的实际内容，于是无视一个事实：直到今天，在世界大部分地区，劳动基金仍然不是以资本的形式出现。”
- 源文实际立场及功能：马克思称资产阶级经济学家的头脑为 `beschränktes Hirn`（狭隘、受限的头脑），说这种头脑无法把表现形式同其中表现的东西区分开；继而用 `schließt die Augen vor der Thatsache`（对事实闭上眼睛）刻画其回避事实。这里既有认识论批判，也有明确的蔑视和“主动不看”的责难，评价对象就是资产阶级经济学家。
- 为什么是 S：中文的“分不清”“无视”保留了认识局限和否认事实的主要批评，没有换错对象，也没有把马克思的判断改成当事人的心理独白；但省去“狭隘头脑”并压缩“闭上眼睛”的主动意象，使蔑视和责难力度变轻，故为 S。
- 建议重译：“资产阶级经济学家那副狭隘头脑，分不清外在形式和其中表现的实际内容，于是对一个事实闭上眼睛：直到今天，在世界大部分地区，劳动基金仍然不是以资本的形式出现。”

### S-04：删去卡尔布典故，使马克思对厂主哀号的戏仿标记消失

- Unit / version / task / source-id：`ch21-s01` / `ch21-s01-v1` / `ch21-p0016-p0020-r1` / `v1-ch21-p0020`
- 当前中文摘录：“鼓励甚至允许劳动力移居国外，资本家怎么办？……抽走工人中的精华，固定资本就会严重贬值……”
- 源文实际立场及功能：厂主波特问完 `what of the capitalist?` 后，马克思立即插入括注：`Dieser Herzensstoß erinnert an Hofmarschall Kalb.` 这不是补充事实，而是把厂主这声“发自肺腑”的自怜比作席勒戏剧中滑稽、做作的宫廷元帅卡尔布，明确提示读者以戏仿和嘲讽距离来听后面的哀号。说话位置从被引厂主短暂切回马克思；讽刺对象是厂主的夸张自怜姿态。
- 为什么是 S：当前中文整个括注缺失，读者失去了这里切回作者声音的显式讽刺标记；不过上下文仍以“工厂主宣言”、把工人叫作“活的劳动机器”，以及后续反讽材料维持总体批判框架，尚未把厂主话语误当成马克思赞同。因此是局部修辞功能删除的 S，而非改变整段立场的 T。
- 建议重译：“鼓励、甚至只是允许劳动力移居国外，资本家怎么办？（这声发自肺腑的哀号，让人想起宫廷元帅卡尔布。）……抽走工人中的精华……”如需照顾普通读者，可附短注说明卡尔布是席勒戏剧中爱摆官腔、举止滑稽的人物。
