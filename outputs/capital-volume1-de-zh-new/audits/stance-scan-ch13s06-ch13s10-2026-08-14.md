## Findings

### ch13-s06

#### S1：把解雇讥称为“放假”的反语被改成平直的“失业”

- Unit / version / task / source-id：`ch13-s06` / `ch13-s06-v2` / `ch13s06-p0001-p0005-r3` / `v1-ch13-s06-p0005`
- 当前中文摘录：“五十人一旦失业，这笔资本也就失去了工作。”
- 源文实际立场及功能：作者正在戏仿“机器释放资本、资本随后会重新找到工人”的补偿理论，故意把五十名工人遭到解雇说成 `Feiertag bekommen`，即被放了“假”。这不是普通时间说明，而是以资本替工人把灾难包装成好事的口吻继续前段关于经济学命名术的讽刺；随后又把生活资料拟人化成坐立不安、寻找投资场所的资本。
- 为什么是 S：现译把反语改成事实性的“失业”，少了一层对补偿理论委婉话术的嘲弄。不过本段仍保留资本“失去工作”“坐立不安”、补偿终于出现以及苦难如尘世财富般短暂等连续讽刺，整体论战读法没有改变。
- 建议重译：“按照这种理论，价值一千五百英镑的生活资料原来是一笔资本，靠那五十名壁纸工人的劳动增殖。那五十人一旦被放了‘大假’，这笔资本也就失去了工作……”

#### S2：矿工被“判入矿井”的谴责意象被降为一般就业描述

- Unit / version / task / source-id：`ch13-s06` / `ch13-s06-v2` / `ch13s06-p0011-p0015-r5` / `v1-ch13-s06-p0011`
- 当前中文摘录：“英国机器体系发展以后，被送进煤矿和金属矿井劳动的人数急剧增加。”
- 源文实际立场及功能：作者说这些人是 `zu Kohlen- und Metallbergwerken verurteilt`，即被“判处”到煤矿和金属矿井劳动。说话者是作者，评价对象不是采矿职业本身的统计名称，而是机器工业扩张所造成的劳动配置；刑罚意象把矿井劳动呈现为人在资本主义工业体系中遭受的判决，先为后文奴隶贸易、驱逐农业工人等代价定调。
- 为什么是 S：“被送进”仍带被动、非自愿色彩，后文又完整保留奴隶贸易、繁殖奴隶和驱逐农业工人的尖锐谴责，所以总体态度清楚；但“被判入矿井”的刑罚力度被明显降低。
- 建议重译：“英国机器体系发展以后，被判进煤矿和金属矿井劳动的人数急剧增加；只是近几十年采矿业也采用新机器，这种增长才有所放慢。”

### ch13-s07

#### S3：报告所谓“改善”工人处境的两处作者讥讽标记被抹平

- Unit / version / task / source-id：`ch13-s07` / `ch13-s07-v1` / `ch13s07-p0001-p0005-r5` / `v1-ch13-s07-p0003`（`note-005`）
- 当前中文摘录：“调查虽然承认并哀叹他们的悲惨处境，却把改善他们处境的办法交给偶然和时间变化。现在，也就是二十年以后，可以希望这些苦难差不多已经消失。”
- 源文实际立场及功能：引文说当局把改善手工织工处境的工作交给偶然和时间，并希望二十年后苦难 `beinahe (nearly)` 已经消失，蒸汽织机的扩张大概促成了这一点。马克思在 `Verbesserung` 后插入 `(!)`，又特意保留英文 `nearly`，讥刺所谓“改善”其实是等待旧工人被机器和时间消耗掉，而连这种消失都只是“差不多”。作者的评价对象是报告这种冷酷的行政乐观主义。
- 为什么是 S：现译准确保留了“承认并哀叹—交给偶然和时间—蒸汽织机促成苦难消失”的事实链，读者仍可能从强烈反差中读出讽刺；但两个显式作者标记均未呈现，使引文表面更像未经标注的平直转述。
- 建议重译：“调查虽然承认并哀叹他们的悲惨处境，却把‘改善’（！）他们处境的工作交给偶然和时间。如今，也就是二十年后，可以希望这些苦难已经‘差不多’消失，而蒸汽织机目前的大规模扩张大概也促成了这一结果。”

### ch13-s10

#### S4：生产者的“受难史”被缓和为一般性的“付出苦难”

- Unit / version / task / source-id：`ch13-s10` / `ch13-s10-v1` / `ch13s10-p0001-p0002-r3` / `v1-ch13-s10-p0002`
- 当前中文摘录：“在农业和工场中，资本主义改造生产过程都会让生产者付出苦难。”
- 源文实际立场及功能：作者用 `Martyrologie der Producenten` 把资本主义改造生产过程称作生产者的“殉难录/受难史”。这不是泛泛承认技术变革有代价，而是把劳动工具成为奴役、剥削和贫困手段，社会化劳动成为有组织压迫等后续判断统摄成一部制度性的生产者受难史。
- 为什么是 S：“付出苦难”保留负面方向，但语气较像一般代价描述，削弱了原文历史性、系统性的控诉。不过紧接着的“奴役、剥削、贫困”“有组织地压制”等判断完整，读者不会把作者立场误读为中性，所以不升为 T。
- 建议重译：“无论在农业还是工场手工业中，资本主义改造生产过程的历史，同时都是一部生产者的受难史：劳动工具变成奴役、剥削并使工人贫困的手段……”
