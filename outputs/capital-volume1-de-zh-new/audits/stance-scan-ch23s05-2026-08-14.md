## Findings

### S-01：马克思自己的贬斥被局部转写成工业资产阶级的看法

- Unit / version / task / source-id：`ch23-s05` / `ch23-s05-v2` / `ch23s05-p0041-p0045-r1` / `v1-ch23s05-p0042`
- 当前中文摘录：“土地贵族不断揭露工厂状况，还装出同情工厂工人的样子，热心推动工厂立法，这让工业资产阶级怒不可遏。在工业资产阶级看来，这些腐朽、冷酷、无所事事的贵族不过是在表演仁慈。”
- 源文实际立场及功能：这句话确实在说明工业资产阶级为何愤怒，但 `grundverdorbnen, herzlosen und vornehmen Müßiggänger` 是叙述者直接给土地贵族加上的贬义定语；`affektirte Sympathie` 和带引号的 `diplomatischen Eifer` 又把他们对工厂工人的同情与立法热心揭成伪善、策略性的表演。紧接着“两个贼打起来”的比喻进一步确认：马克思把工业资本家和土地贵族双方都作为批评对象。
- 为什么是 S：中文保留了“装出同情”、统治阶级两派争论谁剥削得更无耻，以及争吵帮助真相暴露等整体立场，读者仍能恢复马克思对双方的批评；但新增“在工业资产阶级看来”，把“腐朽、冷酷、无所事事”的直接作者评价局部移交给了争斗中的另一派，同时把有引号的策略性“热心”写得较平。因此是局部说话位置和讽刺力度的偏移，尚未改变整段读法，列 S。
- 建议重译：“另一方面，土地贵族揭露工厂状况；这些腐朽、冷酷、养尊处优的闲人装出对工厂工人苦难的同情，还以‘外交式的热心’推动工厂立法，激得工业资产阶级怒不可遏。”

### S-02：工人被“坑骗”的作者评价被中性化为失去工作

- Unit / version / task / source-id：`ch23-s05` / `ch23-s05-v2` / `ch23s05-p0076-p0080-r1` / `v1-ch23s05-p0078`
- 当前中文摘录：“沟的一边，田地明明急需人手。沟的另一边，失去工作的工人只能眼巴巴地望着。”
- 源文实际立场及功能：马克思把沟另一边的工人称作 `die geprellten Arbeiter`，不只是说明他们没有工作，而是直接说他们是“受骗、被坑害的工人”。这个评价把田地明明需要劳动、农场主却不充分耕种且地主合并农场所造成的失业，命名为对工人的坑害；说话者是马克思，评价对象是让工人承担经营决策后果的地主和租地农场主。
- 为什么是 S：中文前文已经明确写出农场主不充分耕种、地主合并农场“于是造成就业不足”，沟两边的反差也完整保留，责任方向并未消失；但“失去工作”只陈述结果，删去了 `geprellten` 的道德评价，使作者的责难略微中性化。因此列 S，而非 T。
- 建议重译：“沟的一边，田地明明急需人手；沟的另一边，被坑害的工人只能眼巴巴地望着。”

### S-03：利润集中数据删去对“赚钱者”和资本家“节制”说的连续讽刺

- Unit / version / task / source-id：`ch23-s05` / `ch23-s05-v2` / `ch23s05-p0121-p0125-r1` / `v1-ch23s05-p0125`
- 当前中文摘录：“表E显示，爱尔兰的利润越来越集中在少数人手里：”表头随后使用“获利者人数”。
- 源文实际立场及功能：马克思列数字时反复把这些利润占有者称为 `Plusmacher`，并把同样的三个人称作 `Virtuosen der „Entsagung“`，说他们把利润 `einsteckten`（装进腰包）。这组命名一面突出极少数人占有巨额利润，一面讽刺把资本收益解释成资本家“节制/禁欲”所得报偿的辩护说法；它不是中性的统计标签。后文“吞下狮子份额”、不公布地租分配、桑格拉多放血等讽刺沿着这一框架继续展开。
- 为什么是 S：当前中文把数据导语和表头中性化，完整删掉了“节制大师”这一理论讽刺；不过同一段后半仍用“吞下”、政府有意不公布、既“不敬”又“不健全”、放血与“千年盛世”等强烈反讽明确维持批评对象和方向，利润集中的事实也没有被当成正面成就。因此是局部修辞功能损失，未改变整段基本读法，列 S。
- 建议重译：“表E显示：1864年，3个获利能手从4,368,610英镑总利润中装进腰包262,819英镑；1865年，还是这3位‘节制’大师，又从4,669,979英镑总利润中拿走274,528英镑。”后续各档可继续称“获利能手”，再接现有的利润集中表。
