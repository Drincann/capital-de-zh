## Findings

### ch11-s01

#### T1：诊断资本如何把工人客体化的“榨取原料”被改成一般关系称谓

- Unit / version / task / source-id：`ch11-s01` / `ch11-s01-v1` / `ch11-p0017-p0020-r2` / `v1-ch11-p0020`
- 当前中文摘录：“它的具体性质来自榨取者同被榨取者之间不可避免的对立。”
- 源文实际立场及功能：作者正在区分共同劳动本身所需的协调，与资本主义指挥作为榨取职能的特殊性质。`der Ausbeuter und das Rohmaterial seiner Ausbeutung` 并不只是给对立双方命名；它有意从资本的榨取视角把活的工人写成可供处理的“原料”，用这种去人格化意象揭露资本指挥的对象化结构。说话者是作者，评价对象是资本主义指挥关系，态度是否定和揭露。
- 为什么是 T：现译保留了“榨取者/被榨取者”的裸命题，却把“工人在这种指挥中被降为榨取原料”的诊断性视角删除了。这样读者仍知道双方有利益对立，却不再看到资本主义管理如何在其自身视野中把人当作材料。该意象在这里承担理论揭露功能，并非可删的装饰，因此属于足以改变读法的中性化。
- 建议重译：“资本家的指挥不仅是社会劳动过程本身所需要的一种特殊职能，同时也是榨取社会劳动过程的职能；它因而以一种不可避免的对立为条件：一边是榨取者，另一边是在这种榨取关系中被当作‘原料’的工人。”

### ch12-s02

#### T2：身体被变成“自动运转的片面器官”，被正面化成“熟练工具”

- Unit / version / task / source-id：`ch12-s02` / `ch12-s02-v1` / `ch12s02-p0001-p0004-r3` / `v1-ch12s02-p0001`
- 当前中文摘录：“一个人如果一辈子只做同一道简单工序，整个身体就会在反复训练中变成专门执行这项动作的熟练工具。”
- 源文实际立场及功能：作者在说明局部工人为何能缩短操作时间时，刻意同时写出代价：终身重复同一简单操作，会把工人的整个身体变成该操作“自动运转的片面器官”（`automatisch einseitiges Organ`）。这是一个双向判断：生产率提高确实发生，但其人体基础是自动化和片面化。批评性身体意象使效率说明同时成为对工场手工业塑造人的方式的诊断。
- 为什么是 T：现译删去“自动”和“片面”，又加入带正面能力评价的“熟练工具”。评价方向因而从“以身体自动化、片面化换取效率”改成“反复训练带来熟练”，读者会把后果主要读成技能提升。这不是单个强度词的损失，而是把同一句中的批判性反面改成正面能力叙述。
- 建议重译：“具体来看，一个工人如果一辈子只做同一道简单工序，整个身体就会变成这道工序自动运转的片面器官。因此，他完成这道工序所用的时间，会少于轮流完成一系列工序的手工业者。”

#### S1：单调劳动“破坏”精神张力，被降为“削弱精神活力”

- Unit / version / task / source-id：`ch12-s02` / `ch12-s02-v1` / `ch12s02-p0001-p0004-r3` / `v1-ch12s02-p0003`
- 当前中文摘录：“不过，连续做单调动作也会削弱人的精神活力。”
- 源文实际立场及功能：作者先说明连续劳动怎样节省转换时的力量，随即用 `zerstört die Spann- und Schwungkraft der Lebensgeister` 作反向限定：持续的同质劳动会“破坏”人的精神张力与活力；活动变化本来正是恢复和刺激的来源。这个强断语阻止读者把生产率增加读成无代价的技术改进。
- 为什么是 S：现译仍保留了负面后果和转折位置，论证的双面性没有消失；只是“削弱”比源文“破坏”明显降调，且“精神活力”压缩了张力与冲劲两个面向，所以列为较小力度差异。
- 建议重译：“不过，持续不断的单调劳动会破坏人的精神张力和活力；而活动本身的变化，原本正能让人恢复精力、得到刺激。”

### ch12-s04

#### S2：对华莱士和汤森的蔑称被中性化为职业称谓

- Unit / version / task / source-id：`ch12-s04` / `ch12-s04-v1` / `ch12s04-p0001-p0004-r1` / `v1-ch12s04-p0004`（`note-003`）
- 当前中文摘录：“除了纯粹空谈的部分，几乎只是抄袭斯图亚特以及华莱士和汤森这两位牧师。”
- 源文实际立场及功能：作者先讥刺马尔萨斯的崇拜者连抄袭关系都不知道，再用 `den Pfaffen Wallace und Townsend` 称呼华莱士和汤森。这里的 `Pfaffen` 不是中性的职业说明，而是带鄙夷的“教士之流”，把对马尔萨斯理论谱系的揭露同对其教士来源的轻蔑绑在一起。
- 为什么是 S：现译“牧师”只报告身份，删去了作者的蔑视。不过“马尔萨斯的崇拜者”“纯粹空谈”“几乎只是抄袭”等主要攻击仍完整，论战对象和结论都没有改变，所以不升为 T。
- 建议重译：“……除了纯属空谈的部分，几乎只是抄袭斯图亚特以及华莱士、汤森这两个教士之流。”

#### S3：马克思插入引文的讥讽性感叹号被删除

- Unit / version / task / source-id：`ch12-s04` / `ch12-s04-v1` / `ch12s04-p0005-p0008-r1` / `v1-ch12s04-p0007`（`note-009`）
- 当前中文摘录：“相反，在那些满足广大人民重大需要的大型制造业中，每个不同工序都雇用大量工人……”
- 源文实际立场及功能：在转引亚当·斯密所谓 `those great manufactures` 时，作者紧接着插入 `(!)`。这个不属于斯密引文的感叹号，标示马克思对斯密把社会分工中的行业称作“大型制造业”的不以为然和讥讽；它与正文对斯密混淆两种分工的批评相互照应。
- 为什么是 S：现译删掉插入符号，使这句话暂时变成平直转述。不过正文已经明确反驳斯密，脚注后半又揭出其名段抄自曼德维尔，读者仍能恢复总体批评位置，因此是局部修辞标记的较小损失。
- 建议重译：“相反，在那些满足广大人民重大需要的‘大型制造业’（！）中，每个不同工序都雇用大量工人……”

### ch12-s05

#### S4：`halbe Idioten` 的刺目措辞被明显缓和

- Unit / version / task / source-id：`ch12-s05` / `ch12-s05-v1` / `ch12s05-p0001-p0004-r3` / `v1-ch12s05-p0004`
- 当前中文摘录：“事实上，18 世纪中叶，有些工场面对某些简单却属于工艺秘密的操作，尤其喜欢雇用智力明显受限的人。”
- 源文实际立场及功能：在引文把工场写成“以人为零件的机器”之后，作者用 `In der That` 接上史实，并直说有些工场 `mit Vorliebe halbe Idioten`。这句刻意粗厉、刺目，评价对象主要是把人的认知受限当作生产优势的工场制度；功能是把前一句“排除精神能力”的制度逻辑推到令人不适的现实结论。
- 为什么是 S：现译保留了“尤其喜欢雇用”这一制度性指控，也没有改变事实方向；但“智力明显受限的人”是较平缓的现代描述，削弱了源句作为段落收束的震动和谴责力度，因此列为 S。
- 建议重译：“事实上，18 世纪中叶，有些工场对某些简单但属于工艺秘密的操作，甚至尤其偏爱雇用近乎痴愚的人。”

## 召回结论

达到阻断阈值的有两处。`v1-ch11-p0020` 保留了榨取对立这一裸命题，却删去了作者借“榨取原料”揭露资本如何把活人客体化的理论视角；`v1-ch12s02-p0001` 则把身体“自动化、片面化”的批判性诊断改成正面的“熟练工具”。两处都改变了作者评价的功能和读者对生产关系/生产率代价的理解，应召回各自采用任务。其余 4 项均为局部力度或讥讽标记损失，不单独触发 recall。
