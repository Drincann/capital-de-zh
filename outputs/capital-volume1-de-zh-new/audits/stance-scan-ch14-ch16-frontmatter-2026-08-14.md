## Findings

### 1. S — “取得公民权”的制度人格化被压成普通合法性判断

- unit/version/task/source-id：`ch15-s04` / `ch15-s04-v1` / `ch15s04-p0001-p0005-r1` / `v1-ch15-s04-p0004`
- 当前中文摘录：“正是在这一时期，无限制延长工作日取得了合法地位。”
- 源文实际立场及功能：马克思说无限延长工作日 `sich das Bürgerrecht erwarb`，把一种剥削实践人格化为取得“公民权”的成员；这不是只报告法律地位，而是用政治共同体的意象讽刺这种实践被社会制度正式接纳。
- 为什么是 S：中文仍清楚表达了“制度认可”及批评方向，没有把对象或因果写错；但“合法地位”变成中性制度说明，削弱了原文反讽性的拟人化。
- 建议重译：“正是在这一时期，无限延长工作日取得了‘公民权’。”

### 2. T — 非美化声明被改成对个人的道德定性

- unit/version/task/source-id：`fm01` / `fm01-v1` / `fm01-p0006-p0010-r1` / `v1-fm01-p0010`
- 当前中文摘录：“我笔下的资本家和土地所有者绝不是正面人物。但我在这里谈到个人，只是因为他们代表着一定的经济地位……”
- 源文实际立场及功能：马克思说自己绝不把资本家和土地所有者的形象画成玫瑰色；紧接着限定，个人在这里仅作为经济范畴的人格化、阶级关系和利益的承担者出现，因此不能把社会关系造成的后果归罪于个人。前句是在声明“不美化描写”，后句是在与个人道德归罪保持距离。
- 为什么是 T：“绝不是正面人物”在现代汉语中把评价对象变成个人品格/人物正邪，并无依据地加强为道德判决；它与后文主动撤回个人归罪的修辞功能相冲突，实质改变作者的说话位置和读者对这一免责声明的理解。
- 建议重译：“我绝没有把资本家和土地所有者描绘成一片玫瑰色。不过，我在这里谈到个人，只限于把他们看作经济范畴的人格化，是特定阶级关系和利益的承担者。”

### 3. S — “私人利益的复仇女神”被还原成一般心理反应

- unit/version/task/source-id：`fm01` / `fm01-v1` / `fm01-p0011-p0015-r2` / `v1-fm01-p0011`
- 当前中文摘录：“私人利益会被触动，于是人心中最激烈、最狭隘、最恶毒的情绪也会出来作战。”
- 源文实际立场及功能：马克思把这些情欲同位称为 `die Furien des Privatinteresses`，即“私人利益的复仇女神”，并说它们被召上战场。神话意象把政治经济学论战写成受私利驱使的报复性围攻，批评强于一般的“情绪被触发”。
- 为什么是 S：“最激烈、最狭隘、最恶毒”和“出来作战”已经保存评价方向、强度与战斗框架；只是复仇女神这一人格化和报复意味被删去。
- 建议重译：“这种研究对象会把人心中最激烈、最狭隘、最恶毒的情欲——私人利益的复仇女神——召上战场。”

### 4. S — “受雇打手式斗殴”的鄙弃意象被压平

- unit/version/task/source-id：`fm02` / `fm02-v1` / `fm02-p0001-p0005-r1` / `v1-fm02-p0005`
- 当前中文摘录：“无私的研究让位于受雇的论战，坦率的科学探索让位于心虚而恶意的辩护。不过，反谷物法同盟……大量散发的小册子……”
- 源文实际立场及功能：马克思用 `bezahlte Klopffechterei` 把资产阶级经济学家的论战写成收钱下场的打手斗殴；又把反谷物法同盟的小册子叫作纠缠人的“小论册”，说它们被抛向世间。整组措辞意在否定其科学身份，并嘲讽其雇佣性、攻击性和聒噪。
- 为什么是 S：“受雇”“心虚而恶意的辩护”“没有科学价值”仍完整保留核心控诉；但“论战”“大量散发”比原文的打手和抛掷意象中性。
- 建议重译：“无私的研究让位于受雇打手式的论战……不过，反谷物法同盟……把那些纠缠不休的小册子抛向世间……”

### 5. S — 面向读者的挖苦被改成作者自述式惊讶

- unit/version/task/source-id：`fm02` / `fm02-v1` / `fm02-p0011-p0015-r1` / `v1-fm02-p0013`
- 当前中文摘录：“另一方面又指责我——真是令人意外——只会批判和分析已有事实，不肯为未来的厨房开出一份配方，大概是孔德式的配方吧。”
- 源文实际立场及功能：`man rathe!` 是直接把读者拉进来的“猜猜看！”，紧接着以 `(comtistische?)` 对所谓未来配方是不是孔德式再补一记怀疑性的侧刺。它把两项互相牵扯的指控当场展示为可笑。
- 为什么是 S：“真是令人意外”和“大概是孔德式”仍保留讽刺方向，读者不会误认这是赞许；只失去了直接挑逗读者、共同嘲笑对手的对话姿态。
- 建议重译：“另一方面——你猜怎么着！——又指责我只会批判地分析现成事实，不肯为未来的厨房开配方（孔德式的？）。”

### 6. S — 马克思的自我反讽“调情”被中性化

- unit/version/task/source-id：`fm02` / `fm02-v1` / `fm02-p0016-p0020-r1` / `v1-fm02-p0019`
- 当前中文摘录：“在讨论价值理论的一章中，有时甚至故意采用他特有的表达方式。”
- 源文实际立场及功能：马克思说自己 `kokettirte`，即在个别地方“同黑格尔特有的表达方式调情”。这是带笑意的自我揭示：他公开承认师承，也有意戏仿/玩用黑格尔语汇，并非只做一次严肃的写作选择说明。
- 为什么是 S：采用黑格尔表达方式的事实和“有意为之”都在；但作者对自身文风的游戏性距离被删掉。
- 建议重译：“在价值理论一章的个别地方，我甚至还同他特有的表达方式调情。”

### 7. S — 资产阶级的价值判断被心理化为“恼火和恐惧”

- unit/version/task/source-id：`fm02` / `fm02-v1` / `fm02-p0016-p0020-r1` / `v1-fm02-p0020`
- 当前中文摘录：“辩证法一旦恢复合理形式，就会让资产阶级及其教条式代言人感到恼火和恐惧。”
- 源文实际立场及功能：`ein Aergerniß und ein Greuel` 不是主要描写人物内心，而是说合理形态的辩证法在资产阶级及其教条代言人看来是一种“冒犯/丑闻”和“可憎之物”。它把他们对辩证法的排斥写成强烈的规范性判斥。
- 为什么是 S：负面方向和很强的敌意仍在，随后“批判的、革命的”也解释了敌意来源；但译文把对辩证法的判斥心理化，弱化了“它本身被视为冒犯与可憎”的语力。
- 建议重译：“辩证法一旦恢复合理形式，在资产阶级及其教条式代言人看来，就是一种冒犯和可憎之物。”

### 8. S — 危机“硬灌辩证法”的惩戒性笑骂减弱

- unit/version/task/source-id：`fm02` / `fm02-v1` / `fm02-p0021-p0023-r1` / `v1-fm02-p0021`
- 当前中文摘录：“甚至会迫使新建立的神圣普鲁士—德意志帝国中那些最走运的人也学会什么叫辩证法。”
- 源文实际立场及功能：马克思把帝国受益者叫作 `Glückspilze`（带戏谑的“幸运儿”），并说危机会把辩证法 `einpauken` 给他们，即像严厉教师一样硬敲、硬灌进脑袋。这里不是一般预测“他们会学会”，而是让危机以惩戒方式教育得意者。
- 为什么是 S：“迫使”“神圣”及对象范围保住了讽刺方向；但学校式强灌和滑稽称谓的力度略有下降。
- 建议重译：“甚至会把辩证法硬灌进这个新‘神圣’普鲁士—德意志帝国的幸运儿脑袋里。”

### 9. S — 对德国经济学术语的“胡言混语”式鄙弃被删去

- unit/version/task/source-id：`fm03` / `fm03-v1` / `fm03-p0006-p0010-r1` / `v1-fm03-p0006`
- 当前中文摘录：“我当然不会把德国经济学家惯用的行话塞进《资本论》。”
- 源文实际立场及功能：恩格斯先称这种表达为通行行话，随即再叫它 `jenes Kauderwälsch`，即不伦不类、叫人听不懂的胡言混语。后面的 Arbeitgeber/Arbeitnehmer 例子是在证明这种术语不只是行内用语，而是荒谬地颠倒施受关系。
- 为什么是 S：“塞进”、后续词义反讽和“法国人会认为他疯了”仍保存明确鄙弃；删除 `Kauderwälsch` 只使开场评价少一层轻蔑。
- 建议重译：“我当然不会把德国经济学家惯用的那套行话——那种不伦不类的胡言混语——塞进《资本论》。”

### 10. S — 对手的羞怯姿态和敌意称呼被中性化

- unit/version/task/source-id：`fm04` / `fm04-v1` / `fm04-p0006-p0010-r1` / `v1-fm04-p0010`
- 当前中文摘录：“只含蓄地说……他还说，《泰晤士报》表达的是《国际工人协会成立宣言》中那句著名引文的‘直接反面’。”
- 源文实际立场及功能：恩格斯说匿名作者 `schamhaft` 地暗示，即带挖苦地写他羞羞答答、不敢直说；匿名作者称该段为 `jene berüchtigte Stelle`（“那段臭名昭著的话”），恩格斯随后加引号重复这一敌意标签，借此反讽对手明明在报道中看到该句仍予以诋毁。
- 为什么是 S：段落仍明确揭露匿名作者的矛盾、隐瞒和花招，也保留大量反讽性引号；但“含蓄”“著名”分别抹去羞怯嘲弄和对手的贬称，局部说话位置变平。
- 建议重译：“他羞羞答答地暗示……又说《泰晤士报》写的是《成立宣言》中那段‘臭名昭著的话’的‘直接反面’。”

### 11. S — 《浮士德》式揭底笑点被改成普通惊叹

- unit/version/task/source-id：`fm04` / `fm04-v1` / `fm04-p0011-p0015-r1` / `v1-fm04-p0014`
- 当前中文摘录：“原来真相竟是这样！”
- 源文实际立场及功能：`Das also war des Pudels Kern!` 化用歌德《浮士德》中“这就是狮子狗的内核”，用戏仿式揭底接上随后圣乔治、地狱恶龙和英雄史诗的整套滑稽夸张。它不只是惊讶，而是宣布剑桥版本的所谓“真相”原来是一场荒唐变形。
- 为什么是 S：下文的“辉煌的英雄史诗”、圣乔治、恶龙和“垂死挣扎”完整保存了总体讽刺，当前句也仍承担揭底功能；仅开头的文学笑点和与后文神魔戏仿的连锁被削弱。
- 建议重译：“原来，这就是‘狮子狗的内核’！〔译者注：化用歌德《浮士德》，意为事情的真相。〕”
