## Findings

### ch02-s01

#### S1：`Geborner Leveller und Cyniker` 的批评色彩变得较温和

- Unit / version / task / source-id：`ch02-s01` / `ch02-s01-v1` / `ch02-p0001-p0005-r2` / `v1-ch02-p0002`
- 当前中文摘录：“因此，商品天生一视同仁，也毫不挑剔。”
- 源文实际立场及功能：作者继续把商品拟人化，称它是天生的“拉平者”和“犬儒主义者”。评价对象是商品作为价值载体时对一切具体商品形态的冷漠；态度带有尖锐讽刺，功能是把价值关系抹平具体差别的机制写成一种毫无顾忌的冷酷性，而不只是性情随和。
- 为什么是 S：现译的“一视同仁”容易带出正面、公平的联想，“毫不挑剔”也比 `Cyniker` 轻快。不过后一句“交换灵魂和肉体”以及马里托尔内的丑陋形象仍保留了讽刺和嫌恶，总体批评读法没有消失，所以不升为 T。
- 建议重译：“因此，商品天生就把一切差别拉平，而且冷漠得毫无顾忌。它随时准备同任何别的商品交换灵魂和肉体……”

### ch03-s01

#### S2：戏谑性的评价从货主移到了商品

- Unit / version / task / source-id：`ch03-s01` / `ch03-s01-v1` / `ch03s01-p0016-p0020-r1` / `v1-ch03s01-p0020`
- 当前中文摘录：“假如铁的所有者想用铁去换某种供人享受的商品，却只向对方指出铁有价格，已经具有货币形式，对方就会……”
- 源文实际立场及功能：`Besitzer einer weltlustigen Waare` 用戏谑语气把交易对手写成持有“贪恋世俗享受之商品”的货主；这个带世俗欲望色彩的对手随后像圣彼得考问但丁一样，要求铁真正变成货币。评价/调侃落在对手一侧，功能是用宗教与世俗享受的反差加强“有价格不等于已经成为现实黄金”。
- 为什么是 S：现译把 `weltlustig` 改挂到商品上，成为中性的“供人享受”，局部说话对象发生移动；但圣彼得—但丁的反讽结构和论证结论仍完整，所以只属较小修辞偏差。
- 建议重译：“假如铁的所有者面对的是一个贪图世俗享受的货主，却只告诉对方铁已有价格、已有货币形式，对方就会像天堂里的圣彼得回答背诵信条的但丁那样回答他：”

### ch03-s02

#### T1：对一种理论理解的直接批评被改成了人的一般认知困难

- Unit / version / task / source-id：`ch03-s02` / `ch03-s02-v1` / `ch03s02-p0001-p0005-r1` / `v1-ch03s02-p0004`
- 当前中文摘录：“人们常常无法正确理解这种形式变化。除了价值概念本身不清楚，还有一个原因……”
- 源文实际立场及功能：作者把评价直接落在“对这种形式变化的理解/看法”上，断言它 `durchaus mangelhaft`，即根本有缺陷；随后把缺陷归因于这套理解没有弄清价值概念，并且只盯住商品与黄金的物质交换。功能不是描述人们偶尔理解困难，而是先否定一种错误的理论把握，再揭示其方法性盲点：它恰好漏掉了应该看的形式变化。
- 为什么是 T：现译一方面把评价对象从“有根本缺陷的理解”换成“人们常常无法理解”的一般心理/认知状态，另一方面把“这套理解没有弄清价值概念”写成“价值概念本身不清楚”。批评的对象、责任归属和力度都改变，读者会把问题读成主题难懂，而不是一种理论看法本身失当。这正是会实质改变作者论战位置的心理化。
- 建议重译：“对这种形式变化的理解之所以根本有缺陷，除了没有弄清价值概念本身，还因为每次商品改变形式，都是通过普通商品同货币商品的交换来完成的。要是只盯住商品同黄金交换这一物质过程，就恰好看不到真正应该考察的东西：商品的形式发生了什么变化。”

#### S3：`Dreck` 的形式讽刺被道德化成“来路肮脏”

- Unit / version / task / source-id：`ch03-s02` / `ch03-s02-v1` / `ch03s02-p0011-p0015-r2` / `v1-ch03s02-p0014`
- 当前中文摘录：“钱可以来路肮脏，肮脏的东西却不等于钱。”
- 源文实际立场及功能：在说明钱的外观抹掉原商品差别之后，作者用 `Geld mag daher Dreck sein, obgleich Dreck nicht Geld ist` 作粗粝的反转：钱可能由粪土/脏东西这类商品变来，但脏东西本身并不因此就是钱。功能是以近乎俚语的方式强调“转化后的货币看不出原商品是什么”，不是判断钱的取得手段是否道德。
- 为什么是 S：现译“来路肮脏”很容易被读成非法或不道德来源，给原文增加了道德判断；不过上下文已经明确说明“看不出由哪一种商品变来”，形式同一性的主论点仍可恢复，因此列为 S。
- 建议重译：“因此，从钱本身看不出它由哪种商品变来。钱可能是由粪土之类的东西换来的，但粪土本身并不是钱。”

#### S4：“价格的爱眼”只剩一般目光，调情意象减弱

- Unit / version / task / source-id：`ch03-s02` / `ch03-s02-v1` / `ch03s02-p0011-p0015-r2` / `v1-ch03s02-p0015`
- 当前中文摘录：“商品的价格就像向货币投来的目光，既在招呼货币，也显示了货币能变成多少商品的界限。”
- 源文实际立场及功能：价格是商品向货币眨动的 `Liebesaugen`，即带求爱意味的“爱眼/媚眼”。商品在诱引货币的同时，也用价格限定货币的变形能力。这个拟人意象把商品“爱货币”的线索同数量界限扣在一起。
- 为什么是 S：现译保留了目光、招呼和吸引关系，论证功能仍然清楚，只是删去了明确的恋爱/调情力度。
- 建议重译：“商品的价格，是商品向货币抛来的媚眼：一面招它过来，一面也告诉它能变成多少商品。这个界限就是货币自身的数量。”

#### S5：标示命题显而易见的轻蔑旁白被删除

- Unit / version / task / source-id：`ch03-s02` / `ch03-s02-v1` / `ch03s02-p0031-p0035-r1` / `v1-ch03s02-p0033`
- 当前中文摘录：“1夸特小麦值2英镑，100夸特就值200英镑，200夸特就值400英镑，依此类推。”
- 源文实际立场及功能：作者先说 `Es gehört wenig Kopfbrechens dazu, um zu begreifen`，即“不用费多少脑筋就能明白”，再给出算例。评价对象是下面这个数量关系的难度；轻蔑而笃定的旁白把它标成无需高深理论的常识，为后面对错误货币观的批评蓄力。
- 为什么是 S：算例及推论完整，读者不会误解命题；只少了作者刻意标示“这本来很简单”的论战语气。
- 建议重译：“不用费多少脑筋就能明白：1夸特小麦值2英镑，100夸特就值200英镑，200夸特就值400英镑，依此类推。”

### ch03-s03

#### S6：社会历史类型被稍微心理化为“头脑简单”

- Unit / version / task / source-id：`ch03-s03` / `ch03-s03-v1` / `ch03s03-p0006-p0010-r1` / `v1-ch03s03-p0008`
- 当前中文摘录：“在头脑简单、近乎野蛮的商品所有者看来，哪怕他是西欧农民，价值也同价值的货币形式分不开。”
- 源文实际立场及功能：`dem barbarisch einfachen Waarenbesitzer, selbst einem westeuropäischen Bauer` 是带讥刺的社会历史定位：即使是西欧农民这种朴素、近乎原始的商品所有者，也把价值同金银这一价值形式混在一起。评价既尖锐，又服务于诊断一种未能区分价值与价值形式的商品所有者立场。
- 为什么是 S：现译保留了商品所有者和西欧农民这两个具体对象，也保留了负面力度；但“头脑简单”更像个人智力评价，稍微遮住了作者在刻画一种朴素商品关系中的社会视野。由于对象和论证功能仍可辨认，列为 S。
- 建议重译：“对朴素得近乎原始的商品所有者——哪怕是西欧农民——来说，价值同它的货币形式分不开。”

#### S7：黄金偶像—禁欲福音的宗教戏仿有所降格

- Unit / version / task / source-id：`ch03-s03` / `ch03-s03-v1` / `ch03s03-p0006-p0010-r1` / `v1-ch03s03-p0009`
- 当前中文摘录：“货币贮藏者因此把自己的物质享受献给黄金这个偶像，真正奉行起节制欲望的信条。”
- 源文实际立场及功能：作者说贮藏者把 `Fleischeslust` 献祭给黄金拜物，并认真践行 `Evangelium der Entsagung`。这是连续的宗教戏仿：肉欲、祭献、偶像、禁欲福音共同把贮藏者的节俭揭示为对黄金拜物的虔敬，而不是普通的消费克制。
- 为什么是 S：“偶像”仍保留拜物批评，勤劳、节俭、吝啬的反讽也还在；但“物质享受/节制欲望的信条”比“肉体欲望/禁欲的福音”明显中性，戏仿力度变小。
- 建议重译：“货币贮藏者因此把肉体享受献祭给黄金这个偶像，认真奉行禁欲的福音。”

#### S8：对资产者“启蒙式自负”的讽刺缩成了中性的自信

- Unit / version / task / source-id：`ch03-s03` / `ch03-s03-v1` / `ch03s03-p0016-p0020-r1` / `v1-ch03s03-p0019`
- 当前中文摘录：“刚才，陶醉于繁荣的资产者还自信地说，货币只是一种空洞幻想，商品才是货币。”
- 源文实际立场及功能：说话者是作者，评价对象是繁荣期资产者的 `Aufklärungsdünkel`，即自以为开明、看透货币的傲慢。作者把这种知识姿态同危机中“只有货币才是商品”的尖叫并置，讥刺资产者的理论自负怎样在现实支付压力前瞬间翻转。
- 为什么是 S：“陶醉于繁荣”“尖叫”“灵魂渴求货币”都保留，整段由自负到恐慌的反讽仍很强；只是“自信”本身偏中性，没有明确传达 `Dünkel` 的傲慢和作者的轻蔑。
- 建议重译：“刚才，陶醉于繁荣的资产者还摆出一副自以为开明、看透一切的傲慢口气，宣称货币只是空洞幻想，商品才是货币。”

## 召回结论

唯一达到阻断阈值的段落是 `v1-ch03s02-p0004`。它不是单纯少了一个强烈形容词，而是把作者对一种理论理解的直接否定，改写成人的一般理解困难，并把这套理解自身的概念混乱移成“价值概念本身不清楚”。这会改变论战对象和责任归属，应召回其采用任务。其余 8 项均为 S，不单独触发 recall。
