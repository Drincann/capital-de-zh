## Findings

### 1. S — “高地浪漫崇拜”的挖苦被写成较普通的山地传奇

- unit/version/source-id：`ch24-s02` / `ch24-s02-v1` / `v1-ch24s02-p0017`
- 当前中文摘录：“勇敢的盖尔人还要为自己把氏族‘大人物’当作山地传奇来崇拜，付出更惨重的代价。”
- 源文实际立场及功能：马克思说盖尔人要为其 `bergromantische Idolatrie` 付出代价，即对氏族“大人物”的山岳浪漫式偶像崇拜。引号中的“大人物”与“偶像崇拜”共同嘲讽一种被浪漫化的依附意识，并解释他们为何在第一次驱逐之后仍受族长再次盘剥。
- 为什么是 S：“崇拜”“大人物”和“付出更惨重代价”仍保存讽刺方向、对象及因果功能；“当作山地传奇”稍弱于“浪漫式偶像崇拜”，但不改变读法。
- 建议重译：“可是，勇敢的盖尔人还要为自己对氏族‘大人物’的山岳浪漫式偶像崇拜，付出更惨重的代价。”

### 2. S — “工人法的后生崽”这一蔑称被中性化

- unit/version/source-id：`ch24-s03` / `ch24-s03-v1` / `v1-ch24s03-p0012`
- 当前中文摘录：“1349年《劳工法》及其后续法律的立场再清楚不过：国家规定工资上限，却绝不规定工资下限。”
- 源文实际立场及功能：马克思称后续法律为《劳工法》的 `Nachgeburten`，即其“后生崽/孽生物”。这个蔑称把一系列工资压制法写成同一敌视工人的制度不断繁殖的产物，随后用“只规定上限、绝无下限”揭示其阶级精神。
- 为什么是 S：中文明确说“后续法律”，并完整保留国家只压工资、不保工资的核心讽刺性对照；只是制度自行繁殖的轻蔑意象消失。
- 建议重译：“1349年《劳工法》及其一窝后生法律的精神再清楚不过：国家规定工资上限，却绝不规定工资下限。”

### 3. S — “劳动营房”被改成中性的“大型劳动场所”

- unit/version/source-id：`ch24-s05` / `ch24-s05-v1` / `v1-ch24s05-p0002`
- 当前中文摘录：“纺锤和织机原本散布在广大乡村，现在同工人和原料一起集中到少数大型劳动场所。”
- 源文实际立场及功能：`Arbeitskasernen` 是“劳动营房/劳动兵营”，把大工场的空间组织比作兵营；它与下句生产工具变成支配工人、榨取无偿劳动的工具相连，用军事纪律意象诊断集中生产对劳动者的统御。
- 为什么是 S：紧随其后的“支配工人、榨取无偿劳动”明确保存制度批评和功能，读者不会把集中化理解为单纯技术进步；但当前称谓抹去兵营式纪律的局部形象。
- 建议重译：“纺锤和织机原本散布在广大乡村，如今同工人和原料一起，被塞进少数大型劳动营房。”

### 4. S — “狼一般的利润饥渴”被弱化为普通欲望增长

- unit/version/source-id：`ch24-s06` / `ch24-s06-v1` / `v1-ch24s06-p0017`
- 当前中文摘录：“工厂主利润极高，欲望也随之增长，于是又实行夜班。”
- 源文实际立场及功能：马克思在引述儿童被鞭打、锁链束缚、逼死乃至逼迫自杀之后，说巨额利润只会磨利工厂主 `Werwohlfsheißhunger`；该排印词形在语境中发挥“狼一般的贪欲/饥渴”作用，把利润欲写成被鲜血进一步刺激的捕食性欲望，并引出昼夜轮班。
- 为什么是 S：上下文已极其明确地呈现厂主以儿童生命换取利润，“欲望随之增长”也保持了利润越高、压榨越甚的方向；但捕食性和道德厌恶的强度明显降低。
- 建议重译：“工厂主利润极高，这只把他们狼一般的利润饥渴磨得更尖，于是又实行夜班。”

### 5. S — 对自由契约辩护的“厚颜胡扯”被压成堂皇说法

- unit/version/source-id：`ch25-s01` / `ch25-s01-v1` / `v1-ch25-p0011`
- 当前中文摘录：“政治经济学家在宗主国可以把它堂而皇之地说成自由的买卖合同……”
- 源文实际立场及功能：马克思说政治经济学家能在宗主国 `breimäulig umlügen` 这种绝对依附关系，即厚着脸、夸夸其谈地把它撒谎改说成平等独立商品所有者的自由契约；殖民地事实则把这个“美丽幻觉”撕碎。措辞不仅批评理论错误，还直接揭露辩护者用谎言掩盖支配关系。
- 为什么是 S：“堂而皇之地说成”与后文“美好幻想破裂”仍让读者看出这是虚假辩护，目标和揭露功能没有丢失；但 `说成` 比“胡扯成/撒谎说成”稍弱。
- 建议重译：“政治经济学家在宗主国可以厚颜无耻地把这种关系胡扯成自由的买卖合同……”

### 6. S — “像火绒一样粉碎”的崩解意象略有压平

- unit/version/source-id：`ch25-s01` / `ch25-s01-v1` / `v1-ch25-p0004`
- 当前中文摘录：“他用来替资本辩护的盔甲，在这里一片片碎掉了。”
- 源文实际立场及功能：`Sein apologetischer Panzer zerbröckelt hier Stück für Stück wie mürber Zunder` 把资本辩护士的理论护甲写成腐朽火绒，殖民地的公开矛盾一碰就逐块化成粉末。它总结了这一节的认识论反转：宗主国中尚可遮掩的阶级对立，在殖民地使辩护体系失去保护力。
- 为什么是 S：“辩护的盔甲”“一片片碎掉”已经保存崩解的对象、方向和总结功能；只少了“腐朽火绒”所带的脆弱、可燃和不堪一击的力度。
- 建议重译：“他用来替资本辩护的盔甲，在这里像朽火绒一样一片片化成粉末。”
