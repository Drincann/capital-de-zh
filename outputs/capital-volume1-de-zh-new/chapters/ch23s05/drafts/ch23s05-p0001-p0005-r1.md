### a. 1846—1866年的英国

要研究资本主义积累，没有哪个时期比刚刚过去的二十年更合适。这二十年里的资本仿佛找到了一个取之不尽的钱袋。在所有国家中，英国又是最典型的例子。它一直占据世界市场的首位，只有这里的资本主义生产方式得到了充分发展。而且，1846年以后，自由贸易所谓“千年盛世”已经到来，庸俗经济学也失去了最后一个推脱现实的借口。这二十年间，生产取得了惊人的进展，后十年又远远超过前十年。第四篇已经充分说明了这一点。

过去半个世纪，英国人口的绝对增加量很大，但相对增速一直下降。下面是官方人口普查的数据。

| 时期 | 英格兰和威尔士人口的年均增长率 |
| --- | ---: |
| 1811—1821年 | 1.533% |
| 1821—1831年 | 1.446% |
| 1831—1841年 | 1.326% |
| 1841—1851年 | 1.216% |
| 1851—1861年 | 1.141% |

再来看另一方面，也就是财富怎样增长。这里最可靠的指标，是缴纳所得税的利润、地租等收入。1853年至1864年，英国应税利润不包括租地农场主和其他少数项目，增长了50.47%，年均增长4.58%。[^94] 同一时期，人口只增长了大约12%。土地等财产的应税租金收入，包括房屋、铁路、矿山和渔业等，增长了38%，年均增长3又5/12%。增长最快的项目如下。[^95]

| 收入来源 | 1864年比1853年增加 | 年均增加 |
| --- | ---: | ---: |
| 房屋 | 38.60% | 3.50% |
| 采石场 | 84.76% | 7.70% |
| 矿山 | 68.85% | 6.26% |
| 炼铁厂 | 39.92% | 3.63% |
| 渔业 | 57.37% | 5.21% |
| 煤气厂 | 126.02% | 11.45% |
| 铁路 | 83.29% | 7.57% |

[^94]: 《英国皇家国内税务委员第十次报告》，伦敦，1866年，第38页。

[^95]: 同上。
