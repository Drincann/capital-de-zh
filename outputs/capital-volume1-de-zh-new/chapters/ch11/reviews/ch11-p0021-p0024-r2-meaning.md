## Source argument map

- [v1-ch11-p0021]: 资本主义管理的内容具有双重性，因为它管理的既是共同生产产品的社会劳动过程，也是资本增殖过程；它的形式则是专制的。协作扩大后，资本家把持续监督交给经理、工头和监工等雇佣人员。政治经济学在别处承认监督可能是额外费用，分析资本主义时却把共同劳动本来需要的协调同资本主义对立关系产生的指挥混为一谈。资本家不是因为管理工业才成为资本家，而是因为已经是资本家才取得工业指挥权。
- [v1-ch11-p0022]: 工人在市场上出售的是彼此分离的个人劳动力，资本家即使购买一百份劳动力，也没有购买这一百人结合起来形成的共同力量。协作只在劳动过程中发生，而那时工人已经被纳入资本。于是，工人作为社会劳动者形成的生产力没有单独付给资本家任何费用，却表现为资本自身固有的生产力。
- [v1-ch11-p0023]: 古代亚洲、埃及和伊特鲁里亚的巨型工程说明，大规模简单协作依靠两种集中：剩余生活资料集中在君主或祭司手中，以及这些统治者能够统一支配大量劳动力。现代社会中，这种组织大批劳动者的权力转到资本家手中，资本家既可以是个人，也可以是股份公司所代表的集体资本。
- [v1-ch11-p0024]: 早期共同体的协作建立在生产条件共有以及个人尚未脱离部落或共同体之上；古代、中世纪和殖民地偶尔出现的大规模协作则多建立在直接统治、依附和奴隶制之上。资本主义协作以出售劳动力的自由雇佣工人为前提，并在历史上同小农和独立手工业相对立。因此，在这些旧生产者面前，协作本身仿佛就是资本主义生产特有的历史形式。
- [note-016 / source note 21a]: 凯尔恩斯把监督列为美国南部奴隶生产的重要特征，并以北部自耕农不需要监督作对照。
- [note-017 / source note 22]: 詹姆斯·斯图亚特用大型制造业越来越接近奴隶劳动的简单形式，说明其摧毁个体生产的社会特点。
- [note-018 / source note 22a]: 以同样逻辑也可以把封建领主说成永远不可缺少，脚注借此讽刺把资本统治者说成永恒必要的论证。
- [note-019 / source note 23]: 琼斯的著作及欧洲收藏的古代文物，为古代大规模协作劳动提供材料。
- [note-020 / source note 23a]: 兰盖把狩猎称为最早的协作形式，又把战争称为最早的狩猎形式之一。
