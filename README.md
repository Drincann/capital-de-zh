# 《资本论》德文直译通俗读者版

这是一个从德文底本出发、面向普通读者的《资本论》第一卷现代汉语翻译工程。

- `outputs/capital-volume1-de-zh-new/`：德文底本、任务、译稿、审校记录、版本和工程状态。
- `capital-progress-app/`：本地进度查看与多版本预览工具。

翻译工程仍在持续进行。正式状态以项目目录中的 manifest 为准。

## 本地查看

进入 `capital-progress-app`，安装依赖后运行：

```powershell
npm start
```

默认在浏览器打开：

```text
http://127.0.0.1:4173
```
